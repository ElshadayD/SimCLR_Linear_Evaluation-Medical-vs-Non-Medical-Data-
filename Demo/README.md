# Lumen: chest X-ray screening app

1. Put `linear_eval_simclr_cxr.pt` in this folder (next to `app.py`).
2. `pip install -r requirements.txt`
3. `python app.py` then open http://127.0.0.1:5000

Use `MODEL_PATH=/path/to/model.pt python app.py` to load the model from elsewhere.
Research demo only, not for clinical use.
